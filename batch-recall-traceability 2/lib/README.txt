Put the Oracle JDBC driver in this folder before running the app:
  ojdbc8.jar  (JDK 8)  or  ojdbc11.jar  (JDK 11 and later)
It is in <ORACLE_HOME>/jdbc/lib/ of your Oracle installation, or downloadable from oracle.com.

To run tests/trace/ui/RuleTests.java, also put h2-2.2.224.jar here (from h2database.com).
Jar files are ignored by git (see .gitignore).
